# Витрина ОМС

Отдельный пакет витрины из [продовой версии ОМС](https://gold-metals.vercel.app/oms) на 25 ноября 2026 года: конфигуратор, самородок в 3D, полноэкранный просмотр и открытие счета. Общая шапка сайта, нижние блоки лендинга, график и FAQ в пакет не входят; внешнюю навигацию предоставляет проект, в который встраивается витрина.

[Макеты, сценарии и корнеры в Figma](https://www.figma.com/design/WHJRaGbXRkAGF3n3sjuJ71/Золото-WEB?node-id=5977-11844). Взаимодействия можно сверять с продом.

## Запуск

Node.js 22.x, npm. Секреты и переменные окружения для запуска не нужны.

```sh
npm ci
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000).

```sh
npm test
npm run typecheck
npm run verify:assets
npm run build
npm start
```

## Где что находится

| Файлы | Назначение |
| --- | --- |
| `app/showcase.tsx` | Состояние веса, курс и соединение витрины с флоу открытия |
| `app/oms/oms-final-hero.tsx`, `oms-final-hero.css` | Общий конфигуратор для мобильной и десктопной версии |
| `app/oms/oms-weight-slider.tsx` | Слайдер, его активное состояние и хаптик |
| `app/oms/nugget-inspection-viewer.tsx` | Переход между хиро и полноэкранным просмотром |
| `app/oms/account-opening-dialog.tsx`, `account-flow.js`, `account-flow.css` | Модалка на десктопе и шторка на мобильном |
| `lib/cbr-gold-server.ts`, `hooks/use-gold-quote.ts` | Получение и обновление курса |
| `public/oms-nugget-viewer/` | Самостоятельная 3D-сцена в iframe |
| `public/oms-hero-lab-v2/weight-scale.js`, `nugget-growth.js` | Шкала веса, расчет доступного веса и морфинг |

Начальный вес — 0,1 г. До 10 г шаг составляет 0,1 г, далее — 1 г, максимум — 1000 г. Значения и сумма обновляются во время ввода; на мобильном ввод не выделяется целиком, Enter закрывает клавиатуру. Перетаскивание слайдера не переводит числовое поле в режим редактирования.

## Флоу открытия

Кнопка «Открыть счет» запускает телефон → код → подтверждение открытия → результат. Подпись цены на экране подтверждения использует текущую стоимость 0,1 г из конфигуратора.

Это тот же локальный прототип, что опубликован на проде: номер и код не покидают страницу, SMS и банковские операции не вызываются. Для проверки подойдет полный российский номер и любые четыре цифры кода. После подтверждения номера открытие требует отдельного нажатия «Открыть счет». Повторная отправка доступна через 60 секунд.

Для просмотра веток можно открыть страницу с параметром `outcome` и пройти те же шаги:

| Адрес | Результат |
| --- | --- |
| `/` или `/?outcome=opened` | Подтверждение открытия → «Золотой счет открыт» |
| `/?outcome=existing` | «У вас уже есть счет» |
| `/?outcome=non-client` | Предложение оформить Black → «Заявка отправлена» |
| `/?outcome=opening-error` | Подтверждение открытия → ошибка открытия |

Параметр нужен только для ревью состояний и не определяет реальный статус клиента. Точки подключения авторизации и открытия счета находятся в `createAccountFlow`: переход после проверки кода и обработчик `account-confirm-action`.

«Купить золото» на успешном результате открывает `tinkoffbank://Main/MetalAccount/Pay`. На мобильном, если страница остается видимой после попытки, появляется предложение скачать приложение. Это эвристика видимости и фокуса; браузер не сообщает, установлено ли приложение. «Скачать» ведет на инструкцию Т-Банка.

## Курс и 3D

Текущий адаптер повторяет прод: получает учетные цены золота из XML Банка России, сохраняет их в памяти на пять минут и использует локальную историю, если запрос недоступен. Клиент обновляет курс каждые пять минут, при возврате на страницу и получении фокуса. Внутренний банковский курс нужно подключить вместо этого адаптера; его API в пакете нет.

3D использует локальные модели, окружение и Three.js r161. После ошибки WebGL или таймаута 30 секунд в хиро появляется изображение выбранного веса. Открытие просмотра повторяет загрузку; успешно загруженная модель остается при возвращении в хиро. Пропорции, вращение, масштаб просмотра, лучи и пыль сохранены из продовой реализации.

Папки с `lab` в имени содержат общие модули, шрифты и статичные кадры, необходимые продовой витрине. Это не дополнительные тестовые страницы. Пути iframe и ресурсов абсолютные, от корня сайта: при встраивании в другой проект нужно сохранить эти пути либо согласованно заменить их в компонентах и сцене. Сообщения между страницей и iframe ограничены тем же origin.

Модели, изображения и фирменные шрифты переданы вместе с реализацией проекта; публичная лицензия на них не предоставляется. Лицензия Three.js сохранена рядом с библиотекой.
